Frequently Asked Questions

Common questions about GLB Viewer, glTF files, and how the tool handles compression and privacy.

What is a .glb file?

A .glb file is the binary form of glTF ("GL Transmission Format"), a standard for 3D models. It packs the scene description (nodes, meshes, materials), all geometry, and all textures into a single binary file, which is why .glb files are the common choice for sharing or previewing a 3D asset as one file.

What's the difference between .glb and .gltf?

They're the same format, packaged differently. .glb is one self-contained binary file. .gltf is a JSON text file that typically references separate texture and binary geometry files alongside it. GLB Viewer opens either.

Is my 3D model uploaded anywhere?

No. The file is read entirely in your browser using local APIs (file.arrayBuffer() and URL.createObjectURL()). There is no backend and no network request ever carries your model's contents.

Does GLB Viewer work offline?

Yes, once the page has loaded once. The 3D renderer (<model-viewer>) and the Draco decoder are both self-hosted with the site rather than pulled from a CDN, so opening and inspecting files keeps working with no network access.

What is Draco compression?

Draco (KHR_draco_mesh_compression) is a glTF extension that compresses mesh geometry to significantly reduce file size. GLB Viewer detects it automatically and decodes it locally using a bundled Draco decoder, with no server round-trip needed.

Does GLB Viewer support Meshopt, WebP, or KTX2?

GLB Viewer detects and flags all of these in the extensionsUsed list shown in the stats panel — Meshopt compression, WebP textures, and KTX2 textures — alongside Draco, so you can see at a glance which optimizations an exported file is using.

Can I compare two 3D models at once?

Yes — drop or pick two files at once, or drag a second file onto the right-hand viewport, to view them side by side. Their cameras stay synced (orbit, target, and field of view), and the stats panel shows the size, triangle count, and texture deltas between the two.

Is GLB Viewer free to use?

Yes, it's completely free, with no signup and no limits.

Is there a file size limit?

There's no limit imposed by the tool itself — the practical ceiling is your browser's available memory, the same as it would be for any other tab handling a large binary file.
